A collection of solutions to Kaggle competitions completed while learning Machine Learning and Deep Learning. Each notebook focuses on solving a real-world prediction problem, covering data preprocessing, feature engineering, model development, evaluation, and submission generation.

The purpose of this repository is to improve practical data science skills by participating in real Kaggle competitions.

# ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/Quantum00000/Kaggle_Compititions.git
```

Navigate into the project

```bash
cd Kaggle_Compititions
```

Install the required packages

```bash
pip install numpy pandas matplotlib scikit-learn torch torchvision jupyter
```

Launch Jupyter Notebook

```bash
jupyter notebook
```

Open any notebook and execute the cells sequentially.
